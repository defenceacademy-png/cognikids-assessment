# CogniKids Cognitive Diagnostic Assessment

**Ages 9–10 · 50 Questions · 45 Minutes**

Standalone online diagnostic test covering:
- Verbal Reasoning
- Numerical Ability
- Non-Verbal Intelligence
- Pattern Recognition
- Spatial Reasoning
- Direction Sense
- Blood Relations
- Calendar Reasoning
- Logical Thinking
- Working Memory
- GK – Indian States
- Classification

## Live Test Link (after enabling Pages)

https://defenceacademy-png.github.io/cognikids-assessment/

## How to enable GitHub Pages

1. Go to the repository: https://github.com/defenceacademy-png/cognikids-assessment
2. Click **Settings** → **Pages** (left sidebar)
3. Under **Source**, select **Deploy from a branch**
4. Branch: **main** / folder: **/ (root)**
5. Click **Save**
6. Wait 1–2 minutes, then open the link above.

## Upload the full test file

If `index.html` is incomplete:
1. Download the complete file from your local copy
2. In the repo, click **Add file** → **Upload files**
3. Drop the full `index.html` and commit

## Features
- Collects child + parent details (name, age, grade, WhatsApp, email)
- One question at a time + 45-min countdown timer
- Section-wise scoring + remarks + improvement tips
- Full answer review with explanations
- Share results via WhatsApp & Email (including academy: defenceacademy@gmail.com)

## Disclaimer
Educational / practice tool only. Not a standardized clinical IQ test.
